## Facilitate one connection

In a live or in-person session, show the full text lifecycle, name the current stage, ask the page's single question, and trace one student's answer to a preceding or following handoff. Allow about 3–5 minutes. For asynchronous participation, use the same short written explanation with public feedback. Students can read without running upstream software; no paid AI account or visual-only response is required.

In Canvas, add the direct page link after the relevant teaching material and guided practice, with a clear optional/recommended label. If completion tracking is useful, use the locally appropriate read/mark-done option. Do not introduce grading or a new required discussion through this repository. Ordinary links let learners choose whether to open a new tab. Test any actual Canvas settings in Student View; editing this repository does not configure Canvas.

## Assess the connection rather than the architecture name

| Evidence | Outcome support | Interpretation limit |
| --- | --- | --- |
| Identify question/input/target and distinguish supervised learning | CLO1, CLO7 support | Does not demonstrate clustering or reinforcement-learning implementation |
| Trace functions, arrays, fitted preprocessing, and layer input/output | CLO4, CLO7 support | Reading does not demonstrate a TensorFlow execution outcome |
| Reconcile committed confusion counts and write a bounded conclusion | CLO8, CLO4 support | Does not independently reproduce upstream metrics |
| Compare the study with the IT and genuine-network examples | CLO2/CLO3 transfer discussion | Medical rows are not IT operational or network-flow evidence |
| Explain a separately evaluated NLP/LLM/fine-tuning/agent component | CLO5 conceptual support | Use the actual module implementation for execution evidence |
| Identify missing inference artifacts and monitoring requirements | CLO6 conceptual support | Does not establish deployment or improved production reliability |
| Explain why attribution is not fairness or clinical validity | RAI extension; advisory A4 | No clinical, fairness, or accreditation certification |

These are existing repository outcome-summary labels, not a new official institutional crosswalk. Advisory A1 analysis, A2 solution evaluation, A3 communication, and A4 ethical judgment describe opportunities only. Check approved program criteria and assessed artifacts before formal ABET mapping; this individual reading route does not establish teamwork.

Verify descriptive links, keyboard/heading navigation, small-screen tables, numerical image equivalents, and effective access to external code.
