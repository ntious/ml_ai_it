# Link a companion module from Canvas

An instructor covering Module 3 can add a clearly labeled external resource link to this repository's Module 3. Learners should arrive at that module's outcomes, prerequisite help, execution steps, original practice, and feedback without completing earlier Canvas assignments.

## Choose a stable destination

For a stable repository destination, use a tested commit:

~~~text
https://github.com/ntious/ml_ai_it/blob/TESTED_COMMIT/docs/lessons/03-data-processing/index.md
~~~

Replace TESTED_COMMIT with the full approved commit SHA. Test the link with a learner account and confirm any source-access requirements.

If serving the built site under the GitHub Pages project base, the corresponding route is:

~~~text
https://ntious.github.io/ml_ai_it/lessons/03-data-processing/
~~~

Use the actual base URL supplied by the host; the address above illustrates the project-route layout. Check the served route before distributing a link. Prefer a tagged tested edition for a semester so instructions and results remain stable.

## Add the resource

In the relevant Canvas module, add an external URL with meaningful text such as “Module 3 companion: data processing, runnable examples, and practice.” Explain that it is an additional resource and identify the core sections you expect students to use. Follow the institution's current Canvas controls; exact labels may differ by installation.

Open the link as a learner, check permissions, heading navigation, downloads, and the route back to Canvas. Include setup and private support information. Do not require an iframe if it makes navigation or authentication harder.

## Suggested description

“This companion resource offers foundation explanations, scripts and notebooks using shared code, optional practice, worked feedback, and advanced extensions. Your course's official assignment, deadline, grading, and AI-use rules remain in Canvas. Advanced extensions are optional unless your instructor explicitly identifies a locally required task.”

## Adapt elsewhere

Use the same module independently in another LMS, an in-person session, or self-study. Do not copy restricted master assessments. Preserve source attribution, offer the [script and reading routes](../accessibility/index.md), and distinguish interpreting a report from demonstrating implementation.
