# Adaptable sequence and pacing

The supplied course sequence has 14 teaching modules. Use the institution's actual calendar and Canvas deadlines. Preparation belongs inside the planned course workload: the syllabus permits students with no programming experience. Python Foundation is recommended learning support, not a newly imposed prerequisite course or a replacement for any institutionally assigned Python resource.

## Plan workload explicitly

Assign selected reading sections and one bounded construction/practice per period. Include preparation, installation, download, independent work and current Canvas assignments in total workload. Do not add all optional extensions on top. Python Foundation estimates about 12 guided hours plus practice; place needed sections early with support and let prepared students demonstrate readiness instead.

For a 16-week offering, insert consolidation after Module 7 and a final synthesis/support period; do not silently move official deadlines. For a shorter calendar, negotiate scope with the course owner rather than rushing every framework concept.

## Asynchronous teaching

Provide a prediction prompt, written worked steps, runnable code, a required independent change and explained feedback. Publish help contact, response expectations, recovery arrangements and an equivalent effective interface. Pair discussion can be replaced with the documented solo reasoning route. No video is required by this OER; institutionally assigned presentations retain their actual requirements and accommodations.

## Advanced depth and consolidation

Use predeclared development robustness, representation, calibration or resource experiments. Ask for a defended tradeoff, not merely a larger model. Revisit ethical questions at framing, data collection and evaluation before the dedicated audit module. Use the [project companion](../project.md) and [pilot instrument](pilot.md) to validate time and transfer. Estimated module times remain provisional until observed with the intended learners.
