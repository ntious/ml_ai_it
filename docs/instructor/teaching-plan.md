# Adaptable sequence and pacing

This is an illustrative 16-week plan, not the institution's Spring 2027 calendar. Confirm local meeting dates, breaks, contact hours, and master-assessment deadlines. Shorter courses can select modules by their prerequisites.

| Week | Focus | Observable learning activity |
| --- | --- | --- |
| 1 | Module 1, setup | Frame a decision and save a changed first run |
| 2 | Module 2 | Trace, modify, and debug a reusable file workflow |
| 3 | Module 3 | Defend a data policy with reconciled row counts |
| 4 | Module 4 | Produce a plot, numerical equivalent, and interpretation |
| 5 | Module 5 | Define forecast availability and compare baselines |
| 6 | Module 6 | Choose a classifier using validation evidence |
| 7 | Module 7 | Interpret clusters without treating IDs as ranks |
| 8 | Consolidation | Reproduce a prior result and repair a documented weakness |
| 9 | Module 8 | Compare actual neural learning with a simple reference |
| 10 | Module 9 | Diagnose imbalanced NLP errors and vocabulary boundaries |
| 11 | Module 10 | Evaluate actual local generation and parsing failures |
| 12 | Module 11 | Explain gradients, adapter replay, and the limits of tiny tuning |
| 13 | Module 12 | Exercise checked inference and monitoring |
| 14 | Module 13 | Audit group evidence and decision consequences |
| 15 | Module 14 | Trace bounded model/tool decisions and refusal |
| 16 | Synthesis | Present a reproducible case and its limits |

## In person

Use a short prediction, live run, paired comparison, and individual explanation. Announce file paths and changes verbally. Provide commands and outputs as selectable text before class. Pairing is optional support, not automatic evidence of teamwork attainment.

## Online

Offer asynchronous reading, the same runnable code, a bounded experiment, and public feedback. Use a solo reflection when synchronous discussion is impractical. Publish support expectations and accessible alternatives. No video has been authored in this edition; future recordings need captions and descriptive transcripts.

## Manage depth

Teach the core decision and simple baseline first. Framework setup and initial model downloads need additional time. Use the separate framework environment. Optional advanced work can explore another dataset, robustness check, or architecture after preserving the core evaluation boundary.

Use [assessment guidance](assessment.md) and local Canvas requirements. Learner piloting is still needed to validate pacing estimates.
