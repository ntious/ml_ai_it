# What's new

Learner-facing notes on what changed. The [changelog](../CHANGELOG.md) has the full record, and [status](status.md) says which revision has been verified.

## Review corrections and additions (October 2026, under review)

These changes are proposed and verified on review branches; they reach the published course when the owner merges them.

- **If a link does not open,** an [offline route](setup/student-workspace.md#if-a-download-link-does-not-open) shows where every download lives in the course source.
- **Setup:** one clearly named notebook kernel for each environment, step-by-step notebook setup, and a WSL route for the framework modules on Windows.
- **Practice:** clearer instructions and feedback that names the call that failed. Modules 1–4, 7 and 9–14 gain a reasoning task and an exercise on the complete study's real results, matching the real-data sandboxes Modules 5, 6 and 8 already had.
- **Concepts:** each concepts page ends with three "Check yourself" questions.
- **New exercises:** stability and tuning (with gradient boosting) in Module 6, categorical encoding in Module 3, evaluated retrieval in Module 10, a JSON API in Module 12, and optional experiment tracking.
- **Finding your way:** a learner-first site menu, [learning paths](paths.md), and maintainer material moved out of search.

Learning outcomes are unchanged.
