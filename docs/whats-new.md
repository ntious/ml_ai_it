# What's new

Learner-facing notes on what changed. The [changelog](../CHANGELOG.md) has the full record, and [status](status.md) explains verification scope and links to commit-specific workflow results.

## Outcome map and bridge activities (November 2026)

- **Reading preferences:** red is the default palette; choose Teal to retain the original colors. The separate Mode control selects System, Light or Dark. Both preferences are saved in your browser when storage is available; no account is required.
- **[Course outcome map](outcome-map.md):** every module now states which course outcomes it supports directly or indirectly, what you produce as evidence, and a clear label for synthetic data, real public data, local models and offline fixtures.
- **Bridge activities (optional):** [interpret network records](cases/network-record-interpretation.md), complete the [IT operations evidence activity](cases/it-operations-evidence.md), write a [monitoring decision record](advanced/monitoring-decision-record.md), and practice a [live API route](advanced/live-api-route.md) with an offline-testable pattern.
- **A responsible-AI question** closes each module's outcome section.
- **Instructors:** an [adoption guide](instructor/adopt-outcomes.md) shows how to map the modules to your own outcomes.

## Review corrections and additions (October 2026)

These changes are part of the current edition.

- **If a link does not open,** an [offline route](setup/student-workspace.md#if-a-download-link-does-not-open) shows where every download lives in the course source.
- **Setup:** one clearly named notebook kernel for each environment, step-by-step notebook setup, and a WSL route for the framework modules on Windows.
- **Practice:** clearer instructions and feedback that names the call that failed. Modules 1–4, 7 and 9–14 gain a reasoning task and an exercise on the complete study's saved outputs (authored fixtures in early modules), matching the real-data sandboxes Modules 5, 6 and 8 already had.
- **Concepts:** each concepts page ends with three "Check yourself" questions.
- **New exercises:** stability and tuning (with gradient boosting) in Module 6, categorical encoding in Module 3, evaluated retrieval in Module 10, a JSON API in Module 12, and optional experiment tracking.
- **Finding your way:** a learner-first site menu, [learning paths](paths.md), and maintainer material moved out of search.

Learning outcomes are unchanged.
