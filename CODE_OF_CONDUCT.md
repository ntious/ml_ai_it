# Community conduct

Help learners ask questions, disagree about evidence and improve materials respectfully. Discuss ideas and reproducible behavior. Avoid harassment, discriminatory language, threats, personal attacks, unwanted contact and sharing another person's private information.

Maintainers may remove harmful contributions, explain corrective action where appropriate and restrict repeated disruption. Apply decisions consistently and protect reporters' privacy.

## Reporting

Use repository issues for nonsensitive community concerns. For a confidential conduct concern, request a confidential reporting channel from maintainers without posting incident details or identifying information. In an adopted course, use the institution's established reporting channels for course-specific concerns.

Accessibility barriers have a dedicated contact: [ntiik@ucmail.uc.edu](mailto:ntiik@ucmail.uc.edu). This address is provided for accessibility issues so maintainers can investigate and address them. See the [accessibility reporting guide](docs/accessibility/index.md).

## Contributions

Preserve attribution and data rights, explain uncertainty, welcome beginner questions and report barriers without requesting a diagnosis. Read [contribution guidance](CONTRIBUTING.md) and the [release/adoption checklist](docs/release-checklist.md).
