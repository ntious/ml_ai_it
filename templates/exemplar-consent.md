# Exemplar consent

Use this record before any learner work is shown as a course exemplar. Keep the signed copy privately with the instructor or maintainer; do not commit it to the repository.

| Item | Response |
| --- | --- |
| Work being shared (title and files) | |
| How it will be credited (name, initials or anonymous) | |
| Where it will appear | |
| Personal, confidential or third-party data removed (yes/no, what was removed) | |
| Instructor approval, if the work was submitted for a course (name, date) | |
| Learner consent (name, date) | |

- Consent is voluntary and does not affect any grade.
- The learner may withdraw consent at any time; the work is then removed from future versions.
- Shared work keeps the course licences for original content and the attribution of any external data.
