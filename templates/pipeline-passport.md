# Pipeline passport

Use this template to explain one complete ML or AI study. Replace the prompts with your own evidence. It supports existing project work or independent study; it sets no grading rule.

## Purpose and data

Name the stakeholder, observation, available input, target/output, error costs, source identity, rights, population/period, and limitations.

## Boundaries and fitted state

Describe the split/group/time rule, training-only preparation, validation choice, final-test boundary, and what changes would require a new evaluation design.

## Handoffs

Record each stage's supplying file/function, input, output, next consumer, saved artifact, and a check. Preserve feature order, shapes, units, IDs, and score meaning.

## Methods and evidence

Name the simple baseline, justified alternatives, actual metrics/denominators, uncertainty, failures, and source/run identity. Separate executed evidence, upstream committed results, interpretations, and proposed work.

## Components and use decision

Explain whether a generative model, fine-tuning, agent, or service has a justified role. If none is needed, say why. For any proposed component define its inputs, permitted output/actions, evaluation, owner, and fallback.

## Communication and access

Write a one-paragraph explanation linking the stages, two concrete handoffs, and one limitation. Provide readable code/text/numerical equivalents. Record assistance and independent verification under local rules; the no-assistant route uses the same evidence.
